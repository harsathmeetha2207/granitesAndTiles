## 🏗️ Architecture Overview

### Layered Architecture

```
┌─────────────────────────────────────┐
│         HTTP Requests               │
├─────────────────────────────────────┤
│      Controller Layer (5 classes)   │  ← REST API Endpoints
├─────────────────────────────────────┤
│      Service Layer (5 classes)      │  ← Business Logic
├─────────────────────────────────────┤
│      Repository Layer (5 interfaces)│  ← JPA Data Access
├─────────────────────────────────────┤
│      Entity Layer (5 classes)       │  ← JPA Entities
├─────────────────────────────────────┤
│      PostgreSQL Database            │  ← Data Storage
└─────────────────────────────────────┘
```

### Design Patterns Used

✅ **CRUD Pattern** - Create, Read, Update, Delete operations
✅ **DTO Pattern** - Data Transfer Objects for API requests/responses
✅ **Repository Pattern** - Data access abstraction using JPA
✅ **Service Pattern** - Business logic encapsulation
✅ **Dependency Injection** - Spring autowiring for loose coupling
✅ **Layered Architecture** - Separation of concerns
